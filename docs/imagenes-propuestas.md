# Imágenes ilustrativas · propuestas (BORRADOR)

Para cada escena del hero y para los 4 casos de Soluciones: **a)** ilustraciones de banco con enlace y licencia, **b)** un prompt para generarla en Magnific con el estilo de la marca. **Nada se descarga ni se usa hasta que Pablo elija.**

## Cómo se aplicaría (cuando Pablo elija)
- unDraw: se descarga el SVG con el color principal en #1F4FE0 y se guarda en `public/img/` con texto alternativo en `content/`.
- Magnific: se generan en 16:10, se revisa que no aparezca texto ni logos, se exportan a WebP y se guardan con su prompt en este archivo.
- Ninguna reemplaza las escenas animadas del hero sin aprobación: hoy el hero usa escenas hechas en código.
